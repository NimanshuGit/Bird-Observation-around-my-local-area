# Bird-Observation-around-my-local-area

This repository is part of my Dear 100 data collection project, where I record bird activity around my local area during the afternoon hours (12:00 PM – 5:00 PM).

Type of data Points which are being Recorded

-->Timestamp: The exact time of day when the birds are observed.

-->Bird Type / Species:** The category or species of birds observed (e.g., Pigeon, Crow, Sparrow).

-->Group Size: The total number of birds in the group.

--> Primary Action: What the birds are doing during the observation (e.g., Foraging, Perched, currently flying, Calling).

--> Height / Level: Where the birds are observed spatially (Ground level, Eye level, or on Roofs/Structures).

--> Environment: The weather and atmospheric conditions at the time of observation (e.g., Sunny, noisy,rainy).
